# Asynchronous HTTP Requests with aiohttp

This snippet demonstrates how to efficiently make multiple HTTP requests asynchronously using the `aiohttp` library, which is particularly useful for web scraping, API consumption, or any I/O-bound tasks.

```python
import aiohttp
import asyncio

async def fetch_url(session, url):
    try:
        async with session.get(url) as response:
            return await response.text()
    except Exception as e:
        print(f"Error fetching {url}: {e}")
        return None

async def fetch_multiple_urls(urls):
    async with aiohttp.ClientSession() as session:
        tasks = [fetch_url(session, url) for url in urls]
        return await asyncio.gather(*tasks)

async def main():
    urls = [
        'https://api.github.com',
        'https://httpbin.org/get',
        'https://jsonplaceholder.typicode.com/posts/1'
    ]
    results = await fetch_multiple_urls(urls)
    for url, content in zip(urls, results):
        print(f"URL: {url}\nContent length: {len(content) if content else 0}\n")

if __name__ == "__main__":
    asyncio.run(main())
```

## Explanation

### What This Code Does
1. Defines an async function `fetch_url` that makes a GET request to a single URL and returns its content
2. Creates a `fetch_multiple_urls` function that processes multiple URLs concurrently using `asyncio.gather`
3. Demonstrates usage with a `main` function that fetches three different API endpoints
4. Prints the URL and content length for each response

### Why It's Useful
- **Performance**: Processes multiple requests concurrently instead of sequentially
- **Modern**: Uses Python's native async/await syntax
- **Robust**: Includes basic error handling for failed requests
- **Versatile**: Can be adapted for any HTTP request scenario

### How to Run
1. Ensure you have Python 3.7+ installed
2. Install required package: `pip install aiohttp`
3. Save the code to a file (e.g., `async_requests.py`)
4. Run with: `python async_requests.py`

### Customization
- Change the `urls` list to target different endpoints
- Modify `fetch_url` to handle different HTTP methods or add headers
- Add response processing (e.g., JSON parsing) within the `fetch_url` function
